Frequently Asked Questions

Is student data secure?
Each student has a completely isolated AI container — no visibility between students. Data is stored on Google Cloud Storage to enterprise security standards. Students are fully isolated and data is automatically cloud-backed.
Will students use AI to cheat?
The AI assistant is designed to support learning, not do homework for students. AI safety scanning automatically detects unusual usage patterns, and the system tracks student usage. The course also teaches students proper AI ethics.
Does it require school IT support?
Minimal IT involvement needed. We provide a complete school admin guide. All that's required is internet access. All setup can be done through a web browser.
Students don't need an email address?
Correct. Primary school students may not have email — we use activation codes + passwords with no email required. After uploading a student CSV, the system automatically generates activation codes.
What devices are supported?
Any device with a browser — computers, tablets, Chromebooks. No software installation required.
What happens when credits run out?
The system alerts you when credits fall below 20%. Schools can top up at any time. Normal usage — 1 million credits per month (~330 Q&A + 50 coding tasks) is very generous for typical school use.
Can we try it first?
Yes! We can arrange a 30-minute live demo showing all features — from the principal dashboard to student AI chat. WhatsApp us to schedule a time.
